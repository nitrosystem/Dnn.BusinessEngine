# Business Engine

**Business Engine** is an open-source application builder for **DNN Platform** that helps developers and organizations build business applications faster — without starting every project from scratch.

Instead of being limited to simple forms and CRUD screens, Business Engine is designed to help you define **business entities, relationships, workflows, actions, data sources, and application logic** through a visual development environment.

### What can you build?

Business Engine can be used to create a wide range of business applications, including:

* Ticketing and support systems
* Management dashboards
* Internal business applications
* Data management systems
* Workflow-driven applications
* Custom CRUD applications
* And much more

### Key Features

* **Visual application builder** for DNN
* Define entities, fields, relationships, and data sources
* Build business logic and application workflows
* Reusable actions and services through an extension-based architecture
* Generate functional applications rather than empty UI shells
* Designed for developers as well as technical teams
* Built to be extensible through custom extensions
* Open source and completely free to use

### Built for DNN

Business Engine is built specifically for **DNN Platform** and **.NET Framework 4.8**.

It integrates with DNN while providing its own application-building environment, allowing developers to create and manage applications directly within their DNN websites.

### Open Source

Business Engine is released under the **MIT License**.

The project is completely free and open source. There is no commercial edition of Business Engine itself.

Its extension-based architecture also makes it possible for the community to build and share additional functionality in the future.
